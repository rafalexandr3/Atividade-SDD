- (event) Iniciativa criada a partir de brief-app-anotacoes/brief-app-anotacoes.md (final, 2026-11-22)
- (decision) Stack: React + Vite + axios + JSON Server; projeto academico MVP; sem backend real
- (decision) Dados: db.json na raiz e gitignored; db-exemplo.json versionado como modelo/seed; json-server usa db.json
- (decision) Modelo de pagina: id, userId, title, type(note|checklist), content para nota, items[{id,text,done}] para checklist
- (decision) Itens de checklist podem ser adicionados e removidos apos a criacao
- (decision) Auth simulada sem token; sessao em localStorage com id do usuario logado; filtro por userId no front-end
- (constraint) Fora do escopo v1: compartilhar, exportar, busca, tags, anexos, editor rico, dark mode, auth com token
- (requirement) R1 (Brief/Scope): Cadastro de usuario com credenciais e login com credenciais cadastradas
- (requirement) R2 (Brief/Solution,Scope): Sessao persiste id do usuario em localStorage; logout limpa sessao e bloqueia area autenticada
- (requirement) R3 (Brief/Solution): Criar, listar, abrir, editar e excluir paginas do usuario autenticado
- (requirement) R4 (Brief/Solution): Pagina tipo note com title e content texto livre
- (requirement) R5 (Brief/Solution,Open question): Pagina tipo checklist com title e items[{id,text,done}], itens marcaveis/desmarcaveis, adicionaveis e removiveis apos criacao
- (requirement) R6 (Brief/Success criteria): Isolamento por userId: conta A nao ve/edita paginas da conta B
- (requirement) R7 (Brief/Success criteria): Projeto roda com npm run dev e json-server; passos documentados no README
- (requirement) R8 (Brief/Scope): Layout utilizavel em 320px a 1440px
- (assumption) Portas e nomes de scripts npm exatos (dev, server) serao definidos no README/tickets; valor padrao json-server 3001 aceitavel
- (assumption) Persistencia 'localmente' atendida por db.json em arquivo local usado pelo json-server; sem banco remoto
